# 01: Foundation shell and visual system

**What to build:** A user can open PeriodPeriods and see a polished, mobile-first application shell with the three planned destinations and clear empty states.

**Blocked by:** None (can start immediately).

**Status:** done

- [x] A React + TypeScript + Vite application starts and builds.
- [x] The shell uses the approved PeriodPeriods visual tokens and local fonts.
- [x] Accueil, Calendrier and Réglages are reachable by touch and keyboard.
- [x] The active destination is visually and semantically identifiable.
- [x] Empty states contain useful explanatory copy and no fake menstrual data.
- [x] The future period-entry action is clearly marked as not implemented in phase 0.
- [x] The layout respects iPhone safe-area insets and reduced-motion preferences.
